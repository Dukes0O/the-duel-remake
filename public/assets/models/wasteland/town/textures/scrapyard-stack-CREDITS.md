# Scrapyard stack reference photos

Generated with the built-in OpenAI image tool on 7 November 2026 for the
TOWN-ART-SERVICES scrapyard model. These are reference photographs of one
stack of crushed compact cars, made for carving: side, front, rear and
straight-down top. The roof width is measured at about 1.4 m. The front and
rear tables in `tools/blender/town-services.py` record the top pixel row for
each end view.

The yard comparison photo, `scrapyard-front.jpg`, and layout photo,
`scrapyard-overhead.jpg`, were already present in this texture folder and are
not generated by this task.
