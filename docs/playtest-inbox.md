# Wasteland play-test inbox

Add a note here after trying a build. Include the event, car, difficulty and
what happened. Screenshots and short recordings help when a problem is visual
or hard to repeat. Do not include saved career data.

## What's new to try

No Wasteland release has been installed in the live game yet. In the private QA
build, try armor-aware rams, traffic wrecks, falling cacti and small trees,
signposts, smoother out-of-bounds recovery, closer checkpoint retries, and the
short UFO jump. Roadside destruction needs the `roadside-destruction` dev flag.
