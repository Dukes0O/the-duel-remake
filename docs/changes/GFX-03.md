# GFX-03: nine fitted Blender armor kits

## Design choice before code

Build one locally loaded GLB per car with fitted named tier/component groups, using each runtime body silhouette and socket layout. Scrapper has plates, bar and stacks; Raider adds cage, guards, saw housings and turret mount; Warlord adds full plating and crown with a reserved warlord-piece mount. These are visual parts of the purchased kit; no new weapon or warlord ability is granted. Fit geometry per car rather than scaling a box uniformly. Use the approved top-panel reference and scrap-plating texture for painted, padded metal UVs, bent edges, bolts and dark understructure. Keep all assets local.

The existing armor-kit module retains the socket registry, four actors, tier and condition thresholds, pooled loose parts, lifetime and replacement/disposal ownership. Geometry is loaded asynchronously through an injectable loader; stale loads must not attach to replaced vehicles or a disposed scene. Preserve the existing synchronous primitives only as a documented load-failure fallback until authored assets are available; they must be hidden/removed once the authored kit loads, never drawn on top. Existing combat-effects owns smoke/fire. Intact, damaged, burning and wrecked appearances derive only from simulation state and time, never mutate them. A wreck retains a scorched/deformed kit shell. Flag-off, ordinary racing and unequipped player remain blank; CPU default Scrapper remains.

Proposed advisory budgets: at most4,000 visible near and1,000 distant kit triangles per car; target two draws, allowing separately breakable pieces only where needed and bounded by measured four-car frame cost. Confirm actual draw count before finalizing geometry; named parts need not all be separate draw calls. Target5MB for the new family, with current8MB single-file advisory. Use shared/local atlases to avoid needless repeated texture bytes. These are card choices, not SPEC limits. Full scene frame time stays within10 percent of baseline in both qualities. No synthetic geometry count substitutes for measurement.

Reversal: rebuild prior kit presentation from its text recipe, preserving purchased loadouts and all simulation behavior. Retain only the currently loaded runtime binaries in the tree; no history rewrite without Kyle.
