# WAR-03d: Tollkeeper

## Rules

Claude settled the gate and rear-valve rules on 5 October 2026. The approved
tanker has no new parts. Its most-rear valve is the core. Existing lamps flash
for the three-second double-damage window. The seeded four-metre gap sits
inside a twelve-metre caltrops strip.

Claude settled the remaining rules on 5 October: the first broken valve resets
both escorts once, then normal 3.5-second returns continue. Escort wrecks do not
score. Losses pay 40 per player-broken valve times difficulty. First wins use
ladder pay and claim the territory; rematches use Warlord pay for the rig only.
The reward is existing Warlord plating on any unlocked car, +30 armor and +270 kg.
