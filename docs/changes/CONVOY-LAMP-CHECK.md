# CONVOY-LAMP-CHECK

The Convoy Raid browser scenario counted roof lamps across the whole tanker.
CONVOY-FRAMES added a distant view that carries its own copy of the two lamps,
so the cold check found four and failed. The check now counts the lamps of the
close-up level only, so it still requires exactly two lamps, cold before the
valves break and lit after. No game code changed.

Removed: nothing.
