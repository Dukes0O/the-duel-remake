# Crew turnaround sheets

Two original front, side and back reference sheets cover Rook, Nell, Jax,
Odessa, Cinder, Dune, Wren and Tusk. Their clothing and silhouettes will
guide CREW-01's selectable crew variants. These are reference images, not
runtime sprites or character textures. The full prompts, original file
hashes and credits are in `docs/WASTELAND_ART.md` and
`public/assets/reference/CREDITS.md`.

One focused art-intake check found both wide opaque PNGs present and valid:
4,442,352 bytes total, no provenance, opacity or size failures. The
generated originals remain unchanged outside the repository.
