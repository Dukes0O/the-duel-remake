# Run all browser scenarios with retained evidence

The five-merge full check found no supported all-scenarios command. Running
each scenario by hand rebuilt `.qa-dist` and removed screenshots from earlier
runs. `node tools/run-browser-scenarios.mjs --all` now finds each named scenario
in `tools/scenarios/`, excludes the separate smoke gate, and runs them in
sequence through the existing private browser harness. It archives each run's
screenshots and report in a disposable temporary folder before the next QA
build. A final JSON summary records every result. The command runs every
scenario even when one fails and exits nonzero if any scenario or warning fails.

It uses the harness's memory-only saves and private ports. It does not open the
live game or real player saves. No production game source changes.
