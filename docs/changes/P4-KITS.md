# P4-KITS

## Decision before implementation

Build 33 reusable donor-based props in six groups. Each gets High and distant
GLBs, metres, glTF Y up and a ground-level pivot. Track cards handle placement
and LOD distances. No track, event, save, collision or race state changes.

Use only Kyle's selected mixes 1, 3, 5, 8, 9 and 11. Record originals, licences,
SHA-256 and adaptations in the existing selected P4 catalog entries. Keep all
26 other records exact. Originals stay in the external art-library; rebuilding
verifies pinned bytes offline and never runs embedded source scripts.

The gantry retains five independent named lamp meshes. The gallery has a
measured 10 m clear road and 4.5 m headroom. Buildings retain donor geometry
with muted worn surfaces; lift parts keep separate movement pivots. Snowman
hat, carrot and snow-body remain separate debris meshes. The original Yeti
skin supplies four real sampled motions: idle, roar, chest-beat and lope.
The distant Yeti must stay at or below 2,000 triangles.

A runtime manifest records source credits and both files for every piece.
About 5 MB added is advisory. No new runtime dependency or network call.
Six source/Blender/native-renderer sheets, each <=500 KB, go to Claude through
the Director. At most three rounds per group. Track-frame cost awaits placement.

## Tests before implementation

The initial native acceptance failed on missing assets before the recipe.
It checks all 33 actual pairs, finite geometry, metric ground pivots, source
pins, LOD reductions/envelopes, independent lamps, actual gallery triangle
clearance, separate debris and four distinct moving clips. The browser uses
real decoded textures and memory-only saves; Node isolates geometry.

## Evidence

All 11 selected entries pin originals and an offline official source page.
Unpacked archive members match exactly. The shared Quaternius licence file
says Ultimate Platformer Pack; the Ultimate Monsters page independently
states CC0. Both originals are retained.

Native checks found and repaired imported editor bone handles, gantry support
collapse and boat/lift envelope loss. The actual 43-joint Yeti remains intact;
Idle/Run supply idle/in-place lope, and roar/chest-beat use authored bone curves.
The stricter distant cap passes at 1,889 triangles. Initial static fitting
repairs retained rock snow caps, fitted braking text to its panel and welded
the donor dome cover before reduction. No replacement dome was constructed.
Before the new structural checks, native acceptance passed on 66 GLBs totaling
44,605 High / 17,685 distant triangles and 7,477,560 bytes.

The production-renderer comparison passed with real decoded textures in both
qualities. Projected bounds and ray tests reject clipped or obstructed views.
The character pose/scale correction passed on private port 53903: eight
captures, no errors and two expected duplicate-Three warnings. All six sheets
are composed. These are preparation evidence, not an art approval.

Sheet inspection found missing distant grandstand seats, collapsed garage
supports, fragments in pine/bank and a missing lower chair frame. The new
first-tread ray failed before repair: 1.735 m to the floor instead of 0.08 m
to the seat. Further witnesses check every tread across three columns, garage
supports, pine cross-sections, bank surfaces and the lower steel chair frame.
Failures are collected in one report; no existing assertion was weakened.
The final repair welds coincident static vertices within each object and
preserves whole props with <=100 triangles. Grandstand LOD removes only its
shallow roof inset and coplanar colour subdivisions: 132/168 triangles, with
all seven treads, their original materials, roof and support witnesses intact.
The chair preserves its steel frame and reduces seat detail: 228/300 triangles.

The bank's concave mounds ruled out a convex-donor assumption. The recipe
verifies closed, consistently wound, positive-volume heightfields. It clips
candidate triangles against covering top facets, requires complete projected
area coverage, and proves strict height ordering at each clipped polygon
vertex. Only 18 ground-hidden base and 23 wholly buried triangles are removed.
Its 91/132-triangle LOD preserves the exact first-hit top profile across 371
dense samples (maximum error 0 m), plus all nine original surface witnesses.
No source shape is replaced and no existing assertion or tolerance is weakened.

After these bounded repairs, all 33 pairs pass native acceptance and all 30
provenance checks pass. Totals are 44,605 High / 18,865 distant triangles and
7,395,888 bytes. Every High GLB and both character pairs are byte-identical to
their prior captures. Five groups received new High/Performance comparisons on private port 62691:
ten screenshots, zero errors and two expected duplicate-Three warnings. The
unchanged character captures were retained only after exact GLB hashes, IDs,
filenames and qualities were checked. Memory-only, real-texture, projected
bounds, occlusion and unchanged race-state checks all passed. This was
functional acceptance during a foreign filtered test, not frame-cost evidence.
The five sheets were rebuilt from those captures; all six are below 500 KB.

Visual inspection confirms the targeted repairs, but also finds deck-plank
loss in the distant dock and pointed tyre shapes. Distant dome/hut surfaces
also need the formal first-round review. These candidates are not finished art.
Python syntax and diff checks pass.

The Director reviewed the non-Factory catalog aggregate and independently

from `c8046da7803aad3bdac783aea1e890ba143bdab67323bbdd996c519e3303ac3f` to

Only the approved aggregate pin changed; Factory provenance and assertions

The Director's source review of the clipping proof and LOD repairs is clear.
Round 1 is frozen for Claude's first formal six-family verdict. Known visual
