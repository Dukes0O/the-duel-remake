## What changed

Added a repeatable private-browser frame sample for High and Performance
quality. It drives the real game UI with disposable memory-only saves and
records 120 frame intervals after 30 settling frames, including the HUD and
rear-view mirror.

## Evidence

- `node --check tools/scenarios/frame-pacing.mjs` passed.
- `node tools/browser-harness.mjs scenario frame-pacing` passed on private
  port 55781 with two screenshots, zero warnings, and zero browser errors.
- High and Performance each measured 16.7 ms p50, 16.8 ms p95, and zero
  intervals over 33 ms. This short sample is a regression check, not a
  frame-rate guarantee.
- The scenario now fixes 1280 × 720 and device ratio 1 to match the previous
  release comparison. A repeat at that size again measured 16.7/16.8 ms in
  both modes with zero intervals over 33 ms. An earlier 1280 × 800 run during
  the full scenario sweep had six High-mode long intervals; an isolated repeat
  at that size had one, so long-tail pacing still needs play testing.

## Behavior and test changes

No game behavior, replay fingerprints, or assertions changed. The browser
scenario suite now includes this frame sample in its `--all` run.
