Build two continuous visual ribbons along the existing wash collision walls at scene-load time. ## Initial design choice before code

Replace the single nine-sided rock column with a continuous, low-poly eroded bank module. Keep its normalized collision box and instanced placement, so every Pacific Canyon route retains the tested wash wall and ground support. Let the bottom ring overlap the ground face within that box, with an irregular but joined slope instead of separate shelves. Vary ridge height and the two faces inside the authored mesh; use deterministic bank orientation for longer-range variation. A more detailed procedural rock texture should follow the slope and strata, rather than repeat the same ledge on every column.

Give steel, soot and wrecks distinct painted texture regions: cool exposed steel, matte soot near fire and seams, worn paint on the hulks, and localized rust at edges. Keep the current three wall texture sets and material draws. Add cables and braces where the gate and towers visibly need support only if the 60,000 triangle wall limit and the 10% loaded-scene frame budget still hold.

Reason: The round-3 review scores wall resemblance 3 and wash resemblance 2. It names repeated ledges, exposed terrain wedges, dark material merging and disconnected gate detail as the main gaps. A different bank shape and localized materials change the approach after one stagnant round for each family.

The first module experiment was reversed after round 5 because the identical instances still read as repeated columns. It remains documented to explain why the joined-ribbon approach was chosen.

Test a 2× box-filter reduction to 512-square for the wall's steel, hulk and detail atlases, keeping the wash's rock atlas at 1024. This changes texture resolution, not the three-set wall allocation, UV layout, material draw count or geometry. Review the same High/Performance camera views before accepting the reduction. The previous 1024 maps can be rebuilt from the earlier script revision if edges or wear lose useful detail.

It failed red on the 1024 wall before code and passed 9/9 after rebuild. The round-7 matched High/Performance sheet showed no visible loss of useful wall detail; later rounds retain the same smaller maps.
