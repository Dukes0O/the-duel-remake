## What changed

The playbook's full check calls `node tools/check-art-intake.mjs`, but that
command did not exist. QA-02 adds a Batch A catalog and a check for every
present image: PNG integrity, dimensions, transparent pixels for sprite
sheets, per-file and batch download budgets, full prompt/date/tool/use in
`docs/WASTELAND_ART.md`, and a nearby credit entry. It reports planned images
that are still absent without claiming they were delivered.

The initial intake budgets are 4.5 MB for a 1024-pixel texture, 12 MB for a
2048-pixel sheet, 8 MB for the wide reference board, and 32 MB for Batch A as
a whole. These are intake limits for runtime copies, not targets for image
generation. The check does not prove visual quality or exact frame alignment;
those need the art look loop before an image ships.

The follow-up requires fully clear background pixels in each sprite sheet cell,
reads RGB transparency keys, and rejects PNG chunk types it cannot safely
decode. Credit entries must name a creator; a statement that Codex did not
make an image no longer counts as a Codex credit. These checks still require a
human to review the art and verify the recorded provenance.
