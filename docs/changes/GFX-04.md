Do not create new drivable terrain or change the physical route.

The yard scene API is `createScrapdomeYard(course, {loadAsset = () => new GLTFLoader().loadAsync('/assets/models/wasteland/scrapdome/yard.glb')})`. `loadAsset()` resolves `{scene:Object3D}`. The factory returns `{group, ready, dispose, setHomeVisible, homeCamera(aspect=16/9)}`. For a hidden-road course, `group.visible=true` from creation so the yard can be seen through the open gate; it has no GLB child until the load completes. `group.userData.assetStatus` is `loading`, `ready`, `failed` or `disabled`, with `loadErrors` for failures. Ordinary courses never invoke the loader and resolve `ready` false. A late load after disposal releases only its own unattached resources, each once. `setHomeVisible(bool)` sets a presentation-only home-active flag; it does not hide the physical yard. `homeCamera` returns null unless that flag is true and the asset is ready. World attachment is limited to a hidden-road course, and the renderer sets home-active only from the guarded arrived/home state. No scene build or GLB generation occurs inside a frame update.

`homeCamera(aspect)` returns world-space `{position:{x,y,z}, target:{x,y,z}, fov}` without touching simulation state. Start with gate-local landscape camera (11,8,8) aimed at (0,3,37), and portrait camera (5,7,9) aimed at (0,3,34); the stopped selected car is near local (0,0,12).
