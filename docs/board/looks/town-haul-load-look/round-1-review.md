27 November 2026, on thirty-four pictures taken in the game on the laptop (Performance quality, the scenario
`town-haul-load-look`, memory-only saves), each beside the picture of the old grey boxes from the same place. The sheet
is `round-1.jpg`.

**The verdict: fails, another round.** Each piece now has its own shape, drawn in code (`src/town/view/haul-load-look.js`),
but the load as a whole does not yet read as a load.
