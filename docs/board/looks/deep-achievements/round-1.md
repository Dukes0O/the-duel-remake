# Achievements shelf

Memory-only `deep-achievements` browser scenario, 1280 by 900. The actual
garage shows three earned achievements (one with its recorded UTC date)
and three gentle hints. Text fits and is readable. A second scenario view
confirms live switches show only Raised from the Deep. Zero browser warnings
or errors. No frame or art-fidelity claim; this uses the existing garage UI.

Reproduce: `node tools/browser-harness.mjs scenario deep-achievements`.
Picture: `round-1.jpg`.
