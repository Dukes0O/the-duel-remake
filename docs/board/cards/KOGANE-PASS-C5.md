## Design settled before code

The lake is right of the road, which is negative lateral in this course's
coordinate system. It shares one basin outline between ground, water drawing
and helicopter scooping. The torii stands in its near shallows, outside the
guardrail. Keep the existing tea house and vending row at positive lateral.
Stone lanterns frame that car park and the small shrine gate near Torii Bend.
Use Tremblant's existing burnt set by reference. The helicopter uses the
existing landing-circle search and the map destination, without a save change.
The course names ambience.kogane in its own definition. The audio renderer
reads that choice from its existing course input. Bell is once per race near
the torii, not once per loop. Stop after the first sheet for Claude's verdict.
