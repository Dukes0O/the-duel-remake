# STORY-FACES

Faces for the talk screen (STORY-TALK). Claude's card: art picks are Claude's.

Six to begin with: Rell, Dace, Wim, Auntie Solder, Cinder, Clinker. Drawn in code first (Kyle, 11 November: code-drawn
before model files), gritty and never toy-like, each told from the others at the size of a thumbnail by its outline
alone. One picture each, 256 px square, with a second for a strong feeling only where a scene needs it. A comparison
sheet goes to Kyle with Claude's pick, as art rounds do.

The talk screen works without them, showing the name alone, so this card holds nothing up.
