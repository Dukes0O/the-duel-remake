# SKI-SAVE: questions for Claude

I am carrying on with the recommended pick in each case. Say if any should change.

**1. The medal comes from the caller.** `recordRun(profile, run, result, {enabled})` takes `result = {time, medal}` for the timed runs (slalom, gs) and `{points, medal}` for the judged ones (moguls, aerials); the ski rules compute the medal (`timedMedal`, `judgedMedal`), and the save keeps the best value, raises the medal and pays the difference up to it (150, 300, 500 in all). The save does not recompute the medal, because `src/heli/` may not import the ski zones and guide (the heli-mode import rule) and the card names only `heli-save.js` as the hook. A caller's medal is clamped to a whole 0 to 3, and a result with a bad number is refused. The pay cannot be farmed: it is capped at 500 a run and 2,000 over the four medal runs. Recommended: keep. Powder has no medal, so `recordRun('powder', ...)` is refused.

**2. Unknown run and stash names are kept, not paid.** Medals can only be earned on the five known runs and the three known stashes (`north-shelf`, `ridge-pocket`, `lower-meadow`, checked against the zone in the test). But a save from a later game (Tremblant's runs and stashes come later) may hold other names inside the same version; the normaliser keeps them (valid ids only, numbers checked) so going back one release loses nothing, and never pays for them. A `ski` record with a newer `version` is left exactly as it is and every write is refused. A newer `heli` version is refused too (the helicopter normaliser treats it as empty, so a write would have overwritten it).

**3. Shape details.** Zero entries are not stored (`medal` and `paid` hold 1 to 3 only); a stored `paid` higher than `medal` raises `medal` to it (a paid medal was earned); a time is kept to a hundredth and points to a tenth. The fixture is `tools/fixtures/saves/19-heli-ski.json` (the next free number), and the save checker (`tools/test-save-fixtures.mjs`) gains one check: a saved `ski` is kept exactly and an older save gains none.
